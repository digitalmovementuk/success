## Notes

- Single page, all asset paths are relative (`assets/`), so the folder also works from any subfolder of a static host.
- The hero film and the mobile hero film are `assets/hero.mp4` and `assets/hero-mobile.mp4`.
- The page is `noindex, nofollow`, so search engines should not list this demo.
- Only files the page references are included here. The separate price list page and unused images from the source folder are not part of this upload.
